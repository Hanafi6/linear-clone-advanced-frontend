# Linear Clone - Advanced Task Management 🚀

نسخة احترافية مستوحاة من تطبيق **Linear** لإدارة المهام، تم بناؤها للتركيز على الأداء العالي وتجربة المستخدم السلسة باستخدام أحدث تقنيات الـ Frontend.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 15 (App Router)
- **State Management:** Zustand & TanStack Query (React Query)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Language:** JavaScript/JSX
- **Icons:** Lucide React

## ✨ المميزات الرئيسية (Key Features)

- **Server-Side Rendering (SSR):** جلب البيانات من السيرفر لضمان سرعة التحميل وتحسين الـ SEO.
- **Dynamic Routing:** صفحات مخصصة لكل مشروع وتاسك باستخدام الداينمك راوتس.
- **Optimistic UI:** تحديث حالة المهام (Done/In Progress) فوراً قبل اكتمال طلب الـ API لتحسين تجربة المستخدم.
- **GitHub-Style Deletion:** نظام حذف المشاريع يتطلب كتابة اسم المشروع للتأكيد (Safe Actions).
- **Responsive Design:** واجهة متجاوبة بالكامل تعمل بكفاءة على جميع أحجام الشاشات.
- **Clean Architecture:** فصل منطق الـ Client عن الـ Server لسهولة الصيانة والتطوير.
